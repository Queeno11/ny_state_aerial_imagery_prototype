# Round 2: robustness of the ranking scorer to the noise law

Signed angle = atan2(θ̂·e2, θ̂·e1) in the H-plane (e1 = θ*); its mean is the bias. Off-plane = norm of θ̂ outside the H-plane (zero for stability arms). Ratio = paired mean f-MSE over RankNet with a global temperature in the same space.

## Pre-registered decision rules

1. Per-cell temperature (RNC) over global (RNG): MSE ratio in B = 0.717 (need < 0.90), in A = 1.025 (need <= 1 within noise) -> **adopt RNC** (small cells; no-stability arms).
2. Switch primary to the surrogate (tau = 0.3) only if, in B-D at the anchor, RankNet (per-cell, with stability) has a significant signed-angle bias with bias^2 >= its variance at (32,40), while SUR03_S does not, and SUR03_S costs <= 1.3x the variance in A:
   - B: RNC_S anchor bias t = -0.15, bias^2 = 1.01e-07 vs small-cell variance 7.09e-04; SUR03_S anchor t = 11.07 -> does not trigger
   - C: RNC_S anchor bias t = -0.93, bias^2 = 2.65e-06 vs small-cell variance 6.95e-04; SUR03_S anchor t = 12.27 -> does not trigger
   - D: RNC_S anchor bias t = -0.74, bias^2 = 2.51e-06 vs small-cell variance 6.72e-04; SUR03_S anchor t = 11.06 -> does not trigger
   - SUR03_S / RNC_S variance in A (small cells): 1.09 (need <= 1.3)
   -> **keep RankNet as primary**
3. Contamination (F, small cells, with stability): SUR03_S / RNC_S MSE = 1.38. A win only here means: keep RankNet as primary and report the surrogate as the contamination-robust variant.
4. Boundary case E (X-dependent skewed noise): ranking estimators should show a significant A1 loading without stability while FE should not; see the table.
